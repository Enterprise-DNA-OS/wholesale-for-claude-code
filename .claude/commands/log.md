---
description: Conversations and decisions onto the record. Calls, promises, supplier excuses, credit decisions. The disputes read it later.
---

1. Run `npm run wholesale -- log "<what happened>" --customer=<name>` (or `--so=<order>` when it belongs to one order).
2. Write it the way it was said, with the date implied by the record: "Louise: payment run Friday. Second Friday so far." beats a paragraph.
3. Log at the moment it happens, not at the end of the day. A promise logged is a follow-up that exists; `task add "<chase>" --customer= --due=` when it needs a date.
4. Notes surface on `customer <name>` and `so <ref>` cards, where the next person (or the next session) actually reads them.
